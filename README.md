# AI Health Screener & Lab Report Explainer

ระบบ AI สำหรับช่วยวิเคราะห์และอธิบายผลตรวจสุขภาพจากภาพเอกสาร
โดยออกแบบให้ผู้ใช้งานทั่วไปสามารถเข้าใจข้อมูลผลตรวจได้ง่ายขึ้น

## Project Overview

โปรเจกต์นี้พัฒนาระบบสำหรับอ่านค่าจากภาพผลตรวจเลือด
และนำข้อมูลมาประเมินเบื้องต้นร่วมกับ AI และ Rule-based Logic

ระบบสามารถวิเคราะห์ค่าที่สำคัญ เช่น

- Glucose
- Cholesterol
- LDL
- HDL

จากนั้นนำค่าที่ได้มาเปรียบเทียบกับช่วงค่ามาตรฐาน
และแสดงผลในรูปแบบภาษาที่เข้าใจง่าย

## Key Features

- วิเคราะห์ผลตรวจสุขภาพจากภาพด้วย AI
- ใช้ Gemini API วิเคราะห์ภาพแบบ Multimodal
- ดึงค่าตัวเลขจากภาพโดยไม่ใช้ OCR แยกขั้นตอน
- เปรียบเทียบค่าผลตรวจด้วย Rule-based Logic
- ใช้ Prompt Engineering เพื่อสร้างคำอธิบายที่เข้าใจง่าย
- แสดงคำแนะนำเบื้องต้นจากผลการประเมิน

## Technologies

- Gemini API
- AI / Multimodal
- Prompt Engineering
- Rule-based Logic
- Web Application

## Project Structure

- `Web App/` — ไฟล์ของระบบ Web Application
- `Images/` — ภาพประกอบและภาพหน้าจอของโปรเจกต์
- `PDF/` — เอกสารและรายงานของโปรเจกต์
- `Video/` — สื่อวิดีโอแสดงการทำงานของระบบ
